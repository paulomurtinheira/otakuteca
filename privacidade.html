Otakuteca · Política de Privacidade

Última atualização: 20 de novembro de 2026

A Otakuteca é uma app gratuita e de código aberto para organizares a tua lista de anime e manga. Não temos servidores próprios: a app corre no teu dispositivo e não recolhemos, vemos nem guardamos os teus dados.

O que fica guardado e onde

A tua lista, notas, classificações e definições ficam guardadas no teu próprio dispositivo (no armazenamento local do navegador).

Entrar com Google (opcional)

Se escolheres "Entrar com Google", a app pede ao Google duas coisas:

  • o teu email e nome, só para mostrar com que conta estás ligado;
  • acesso à pasta privada da app no teu Google Drive (permissão drive.appdata), onde guarda um único ficheiro com a tua lista, para a poderes usar em vários dispositivos.

Essa pasta é só da Otakuteca: a app não vê nem altera nenhum outro ficheiro do teu Drive, e nem sequer vês essa pasta no Drive. Os dados vão diretamente do teu dispositivo para o teu Google Drive. Não passam por nenhum servidor nosso e nós não temos acesso a eles. Podes retirar o acesso a qualquer momento em myaccount.google.com/permissions, ou com o botão "Terminar sessão" nas Definições da app.

O uso das informações recebidas das APIs da Google respeita a Política de Dados de Utilizador dos Serviços de API da Google, incluindo os requisitos de Utilização Limitada.

Sincronização com o GitHub (opcional)

Em alternativa, podes ligar a app a um repositório teu no GitHub com um token que crias tu. O token fica apenas no teu dispositivo e é usado só para guardar e ler a tua lista nesse repositório.

Serviços externos

Para pesquisar títulos e mostrar capas, a app consulta a API pública do AniList. Os termos que pesquisas são enviados ao AniList, sem qualquer informação pessoal. Os links dos teus sites favoritos abrem num novo separador, sem enviar referrer.

Partilha e venda de dados

Não vendemos, não partilhamos e não usamos os teus dados para publicidade nem para treinar modelos de IA.

Apagar os teus dados

Nas Definições da app podes apagar a lista guardada no aparelho. Os dados da app no Google Drive ficam na pasta privada da Otakuteca até os removeres: em drive.google.com/drive/settings → "Gerir aplicações", escolhe a Otakuteca e "Eliminar dados da aplicação oculta".
